# Elevate for Windows

**Simple presentation software for churches.** Song lyrics, the Bible, sermons, pictures, videos and PDFs on the
projector, the stage monitor and every TV in the building, from one laptop. A simple alternative to ProPresenter and
Proclaim that a volunteer can run on their first Sunday.

**Website:** [presentall.vercel.app](https://presentall.vercel.app) ·
**Help:** [Get started](https://presentall.vercel.app/docs) ·
**Contact:** getelevatesupport@gmail.com

## Download

1. Open the **[newest release](https://github.com/booladsudan/elevate-releases/releases/latest)**.
2. Under **Assets**, download **`Elevate-Setup-<version>.exe`** (for example `Elevate-Setup-1.2.0.exe`).
   You only need this one file; the others are used by Elevate to update itself.

## Install

1. Open the file you downloaded.
2. If Windows says **"Windows protected your PC"**, click **More info**, then **Run anyway**.
   (Windows shows this for apps from smaller publishers. Elevate is safe to install.)
3. Elevate installs in a few seconds and opens by itself.

## Start using it

- **No account needed.** Your songs, services, sermons, pictures and videos are kept on this computer.
- **Works without the internet.** Nothing on screen stops if the connection drops.
- **The output opens by itself** full screen on your projector or TV. Connect it with HDMI (or a USB‑C / DisplayPort
  adapter) and set Windows to **Extend** the display, not Duplicate.
- **Make a backup now and then:** Settings → Organization → Backup → **Back up now**, and keep the file on a USB stick
  or in a cloud folder. Everything lives on this one computer.
- **Want a team, the same library on several computers, share links or screens over the internet?** Sign in or create
  an account in the app. Those extras come with **Elevate Plus**.

## Updates

Elevate keeps itself up to date. A new version downloads in the background and installs the next time you close
Elevate, so it never interrupts a service. What changed in each version is written on its
[release page](https://github.com/booladsudan/elevate-releases/releases).

## What you need

- A computer with **Windows 10 or 11** (64-bit).
- A projector or TV as a **second screen** (optional: the Live panel shows exactly what would be on screen).
- A Mac version isn't available yet. On a Mac, Linux or Chromebook, use Elevate in the browser at
  [presentall.vercel.app](https://presentall.vercel.app) (Chrome or Edge).
